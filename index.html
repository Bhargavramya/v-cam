    Set up once

    1 · Home screen

    1. In Safari: Share → Add to Home Screen → Add.
    2. Always open V Cam from that icon.

    2 · iPhone album

    1. Photos → Albums → + → New Album → Varnana Items.

    3 · Shortcut

    1. Shortcuts → + → Add Action → Save to Photo Album.
    2. Change Recents to Varnana Items.
    3. Rename it Save to Varnana Items, turn on Show in Share Sheet, Done.

    Every save

    1. Save to Photos (or select many → Photos) → tap Save to Varnana Items.
